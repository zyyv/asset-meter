Press F5 to open the demo in an Extension Development Host:

1. Install or update the native Explorer patch, then reload. Folder labels show counts first and sizes last, such as `3 files · 2.3 KB`.
2. Only the size text uses yellow, orange or red severity colors. Filenames retain their theme and Git colors.
3. Run **Asset Meter: Toggle Always / Hover** to change the display mode.
